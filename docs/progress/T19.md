## Assumptions

- **Ports.** The orchestrator reserved ports 3190–3199 for this run, so Playwright uses 3191 and Lighthouse 3192. `scripts/serve.ts` still defaults to 3301 as ARCHITECTURE says, and `SITE_E2E_PORT` overrides the e2e port.
- **Pricing.** The PRD hypothesis of R$ 149 per field user per month is the only price, and it is hidden by default. The default pricing page invites a conversation.
- **Contact defaults.** The default WhatsApp number `+5511999999999` and the addresses `contato@` and `privacidade@agrorende.com.br` are placeholders; the build reads the real values from the environment.
- **`TERMS_VERSION`.** It defaults to `2026-10-08` and is passed to the site build from the same GitHub variable the web app uses.
- **RSC payloads.** The `.txt` payload files are deleted after export, because the site has no client-side navigation and they only added weight.
- **Help-page payload.** The help page passes the error index to its client search as compact `[code, title]` tuples. The rows use one CSS class instead of repeated utilities and an SVG per row, and the code labels use the system monospace font. Together these keep the heaviest page under the 2.5 s LCP budget; it was at 2.5 s before.
- **Hydration.** Inline scripts only touch `<html>` attributes and redirects; text that depends on the query string is rendered by client components, because React hydrates the whole document.
- **Release artifact.** The release `site` artifact is built for production (`vars.SITE_HOST`, falling back to `agrorende.com.br`). `deploy.yml` rebuilds per environment so staging never carries production canonical URLs.
