## Assumptions
- A report's title falls back to the localised category label when the user leaves it empty.
- Withdraw is idempotent. A withdrawn report is stored as DISMISSED with `statusReason` `WITHDRAWN: <reason>` and `flags.withdrawn = true`.
- Any transition that is not allowed answers `REPORT_LOCKED`. Update and withdraw are only allowed while the report is SUBMITTED.
- When the rental seam is not wired, the active rental is taken from `asset.currentRentalId`.
- The mobile report id equals the wizard draft id, so media captured before Send already carry the right parent.
- The wizard limits videos itself, through `acceptMediaChange` and `allowVideo`, because `MediaCapture` has no limit option.
- Same-wave seams are mocked in tests (R12): T07 `workOrderSeams.createFromSource`, T07 `GET /work-orders/suggestions` (the dialog uses the api-client types only), and T08 `rentalSeams.activeRentalForAsset`.
