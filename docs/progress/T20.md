## Done
- TEN-01: self-service company sign-up.
  - The sign-up ticket and login code (`packages/core/src/modules/tenancy/signupTicket.ts`) are short-lived, single-use, bound to the verified Google or Apple identity, and use PKCE for the app.
  - `signupOrganization` creates the organisation, its default settings and seed data, and the creator as ADMIN in one transaction (`service.ts`, `defaults.ts`). It requires the office phone (E.164), validates the CNPJ (`taxId.ts`) and the timezone, requires terms acceptance, rate-limits 5 requests per IP per day and enforces same-origin CSRF.
  - `POST /api/v1/signup/organization` route.
  - Web pages `/signup` (Google and Apple start) and `/signup/company` (company form with field errors, a restart action on `OAUTH_STATE_EXPIRED`, and links to the legal pages) in `apps/web/src/features/signup/**`.
- TEN-02: `OrgStatus` lifecycle.
  - `lifecycle.ts`: TRIAL → PAST_DUE when `trialEndsAt` passes; PAST_DUE → SUSPENDED after 14 days; CANCELLED keeps `purgeAfter` 90 days out.
  - `applyStatusChange` writes the `org:status` outbox event, and reactivation also writes `sync:poke`.
  - Role-aware web banner (`features/tenancy/orgBanner.ts`, `TenancyOrgBanner.tsx`, `OrgStatusBanner.tsx`):
    - TRIAL: ADMIN only.
    - PAST_DUE: ADMIN with an action, MANAGER with a notice.
    - SUSPENDED and CANCELLED: read-only copy with a WhatsApp support action (`PLATFORM_SUPPORT_WHATSAPP`). This is EC-OPS-29.
    - FIELD users never see the web banner.
- TEN-03 / EC-PLT-40 (server side): `assertOrgWritable` makes SUSPENDED and CANCELLED organisations read-only, and `orgStatus()` feeds the T02 push gate (7-day grace, then RETRY). The mobile `OrgStatusBanner` shows "Company access paused / Keep recording…" for SUSPENDED and CANCELLED (`apps/mobile/src/features/tenancy/OrgStatusBanner.tsx`, `src/i18n/*/tenancy.json`).
- TEN-04: Settings → Subscription, `/settings/subscription` (`features/subscription/**`). It shows:
  - status explanation and plan
  - a countdown meter for the trial, grace or export window
  - the export guidance link to `/reports` when read-only
  - monthly usage
  - terms re-acceptance (`POST /api/v1/org/accept-terms`, `TERMS_VERSION`)
  - cancellation with typed-name confirmation (`POST /api/v1/org/cancel`)
  - the WhatsApp support link
  - Data comes from `GET /api/v1/org/subscription`, which is ADMIN only.
- TEN-05: `usage.ts` (`runUsageDaily`) computes the monthly `OrgUsage` row idempotently for each organisation: active field users, office users, storage bytes and assets. Worker job `apps/worker/src/jobs/usage.daily.ts`.
- TEN-06: platform console.
  - Staff Google OIDC sign-in with state, nonce and PKCE, plus the `PLATFORM_ADMIN_EMAILS` allow-list, issues the `ar_platform` cookie (8 h, SameSite=Strict). Logout route. Code in `platform.ts`.
  - Organisation list and detail return metadata, usage, admins and audit only.
  - `PATCH` changes status, plan or `trialEndsAt` and requires a reason.
  - Admin reset link: an ADMIN of that organisation only, returned as a share link.
  - Every staff action writes `platform_audit_events`.
  - Tenant tokens get `UNAUTHENTICATED`.
  - Pages `/platform/login`, `/platform/orgs` and `/platform/orgs/[id]` (`features/platform/**`, `app/(platform)/**`).
- TEN-07: `purge.ts` (`runOrgPurge`) deletes the rows and the `MEDIA_ROOT/org/<id>` folder of CANCELLED organisations past `purgeAfter` only, refuses a path that escapes the media root, and audits `org.purge`. Worker jobs `orgs.lifecycle.ts` and `orgs.purge.ts`.
- TEN-10: getting-started checklist.
  - `gettingStarted()` covers four steps: assets, team, QR labels and app installed.
  - Web `GettingStartedCard` and `features/onboarding/GettingStartedPanel.tsx`, which is ADMIN only and hides itself when complete.

## Assumptions
- `POST /api/v1/platform/auth/logout` was added. It clears `ar_platform` so staff can sign out from the console header.
- The purge audit actor is `system@agrorende.app`.
- The `createdById` of the admin reset link is the target admin, because staff are not tenant users.
- Legal page URLs on the public site: `/pt-br/termos|privacidade|dpa` and `/en/terms|privacy|dpa` under `SITE_URL`, falling back to `http://localhost:3300`. T21 owns the site.

- Getting-started links: assets → `/assets`, team → `/team`, QR labels → `/assets`, app install → `/team`.
- Export guidance points to `/reports`, the existing export entry point.
- Day counts round up (`ceil`), so "1 day left" shows until the instant passes.
- Platform `PATCH` with `trialEndsAt` from the date input sends the end of that day in UTC.
- Mobile shows the paused banner only for SUSPENDED and CANCELLED. TRIAL and PAST_DUE are office concerns and are not shown to field users.
- The mobile test lives in `apps/mobile/test/ui/tenancy.test.tsx`, the Jest UI project's test folder, next to `reports.test.tsx`. It only exercises T20's component.
- The worker test uses `.data/media-t20/tenancy-jobs-test`, so it never collides with T05's `<MEDIA_ROOT>/worker-test`, which T05 cleans with `rm -rf`.
