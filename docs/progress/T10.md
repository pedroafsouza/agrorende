## Assumptions

- **`workOrders/external.ts`.** The AC expects it to be a `notImplemented` placeholder. The real implementation already shipped with a live route and a test, so it was moved into `external.ts` rather than replaced by a stub. The grep therefore returns only the definition in `context.ts`. This keeps the W6 split the AC is for (T14 owns `external.ts`) without regressing shipped behaviour.
- **Golden-path spec over card.** Where the T10 card and the specification disagree, the golden path asserts the specification:
  - No RESOLVED report status exists, so the report stays MARKED_FOR_REPAIR after verification.
  - A MODERATE dent does not set NEEDS_REPAIR at check-in (§6.4).
  - §6.5 has no WO_COMPLETED notification, so `entity:changed` and `activity:new` are asserted instead.
  - Marina's mobile pull scope (§7.5) excludes other users' reports and completed work orders.
- **Who creates the rental.** Creating and reserving a rental is office-only, so Marina creates it with Rafael as agent. Rafael does the check-out and check-in on the device.
- **Golden-path clock.** OAuth uses the real clock, because the mock signs tokens with real time. The story uses `vi.useFakeTimers({ toFake: ["Date"], shouldAdvanceTime: true })` with `vi.setSystemTime` per step.
- **Live run database.** The live run used its own `agrorende_t10_live` database so the shared `agrorende` demo database was not reset.
- **Lockfile.** The core package needed `@agrorende/i18n` for the server catalogues. Adding this workspace link updated `pnpm-lock.yaml` through `pnpm install --offline`: one importer link was added, and `bufferutil` and `utf-8-validate` left one transitive peer list. No external package was added.
- **OAuth decisions.**
  - A verified email that matches a joined member without an identity for that provider links the identity (EC-PLT-34).
  - Apple's web flow carries the nonce in an encrypted state, because the cross-site `form_post` drops Lax cookies.
- **Smoke data.** Each smoke run leaves one field report, one photo and one export job behind, and reuses two fixed device ids.
