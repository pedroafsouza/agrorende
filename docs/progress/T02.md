## Assumptions
- Passwords use scrypt from `node:crypto` because `@node-rs/argon2` is not a dependency (T02-001). Seed `sha256:` hashes are upgraded on login.
- When a refresh token is reused inside the 30-second grace, a new pair is issued in the same family. Outside the grace, the whole family is revoked.
- A disabled user's drain token travels in the `ACCOUNT_DISABLED` error details.
- The account-deletion confirmation word is `DELETE` or `EXCLUIR`. The anonymised name is `#<first 8 characters of the id>`.
- The WhatsApp share text for invites and resets is the URL only. The URLs are `/i/<code>` and `/r/<code>`.
- The device platform defaults to `ANDROID` when it is omitted.
- Maximum media sizes are set per kind.
- Completing a single upload that has no staged file returns `MEDIA_PART_MISSING`.
- An expired GET media token returns `FORBIDDEN`. Upload tokens return `UPLOAD_URL_EXPIRED` (410).
- `/media/:id/url` answers 302 with `cache-control: private, max-age=240`.
- The notification list response adds `unreadCount`.
- `GET /settings` is open to any authenticated user and carries an ETag.
- A pull request without `scopeEpoch` is treated as epoch 0.
- Notification templates live in `packages/core/src/notify/templates.ts` until T02-005 is applied.
- The 5-second timeout in T01's `withSyncTx.test.ts` was occasionally hit under load; it is pre-existing.
