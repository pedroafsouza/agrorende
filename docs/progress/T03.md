## Done
- OFF-01…OFF-04, PLT-12-ready (A§7.1): local SQLite database with a drizzle schema for every synced entity plus `outbox` (`inFlightAt`, `pushAttemptId`), `media_files`, `drafts`, `sync_state`, `conflicts`, `diagnostics_queue` (capped at 500 rows and 7 days) and `location_buffer`. Includes bundled migrations, an OTA gate that runs migrations only after the new bundle has launched once, `quickCheck` with a backup copy, and a per-user database file (`apps/mobile/src/db/**`). The client mirror of the server collections is generated from the contracts (`src/db/codegen`, `mirror.generated.ts`).
- OFF-05…OFF-16 (A§7.2–7.6, A§7.10): the sync engine (`apps/mobile/src/sync/**`):
  - Mutator → outbox in one transaction, with payload validation against `@agrorende/contracts` before anything is written.
  - Push with client `resolvedMutations`, and apply where the server wins and the `_dirty` rows are rebased.
  - IN_FLIGHT recovery at start and after network failures.
  - Pull paging with tombstones, and a scope-reset rebase that deletes only clean rows and replays pending mutators.
  - Eviction that never drops rows with pending work.
  - Triggers: foreground, connectivity regained, interval, `sync:poke`, and `expo-background-task`.
  - A `GET /api/v1/health` captive-portal probe before credentialed calls.
  - Essential-first mode on slow networks, prioritised first sync and capped backoff.
  - Conflict records with plain-language messages, a reset that keeps the outbox, and diagnostics redaction.
- T03 mutators: `media.*`, `user.setDuty`, `asset.updateReadings` and `notification.markRead` (`src/sync/mutators/**`). Feature mutators are left to T06–T08.
- Media pipeline (A§7.7, `src/media/**`):
  - Processing and durable files.
  - An upload queue with priorities (signature, then photo, then video); thumbnails before originals; single and multipart uploads that resume from recorded ETags; Wi-Fi-only videos.
  - Terminal-versus-retry error handling, pruning, a free-space guard, and discarding an unsent capture.
- Location (A§7.8, `src/location/**`): consent flow, and foreground and background tracking only while the user is ON_DUTY. The buffer flushes over the socket and marks fixes sent only after the ack, falls back to REST in batches of 500, and thins old points while keeping the last 48 hours.
- Realtime client (`src/realtime/**`): Socket.IO adapter, pokes that kick a sync, and location batches resolved on ack.
- PLT-01…PLT-05, PLT-09, PLT-14 and PLT-15 (auth, `src/auth/**`):

  - Secure-store token vault and an offline session from the cached profile.
  - Single-flight refresh with rotation, and a non-destructive "sign in again" state on 401.
  - Login, change-password and onboarding screens (`src/auth/ui/**`, `app/(auth)/**`).
