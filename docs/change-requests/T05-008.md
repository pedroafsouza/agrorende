# T05-008 · User notification mute settings

Status: OPEN
Requested by: T05 · Wave: W2
Target: `packages/db/src/schemas/index.ts` `UserSchema`, `packages/contracts` user DTO (owner: T01)
Kind: schema

## Problem
ARCHITECTURE §10 says `notifications.push` respects user mute settings, but `User` has no such field.

## Proposed change
Add `notificationPrefs: { pushMuted: boolean; mutedTypes: NotificationType[] }` (default `{ pushMuted: false, mutedTypes: [] }`) to `User`. The push job would then skip those users or types.

## Workaround in place
The push job sends to every active user who has an `OK` device token.

## Impact if rejected
Users cannot mute push notifications.
