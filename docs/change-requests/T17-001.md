Status: OPEN
Requested by: T17 · Wave: W6
Target: `packages/core/src/__tests__/tenancy.test.ts` (owner: T10)
Kind: other

## Problem
T17 replaced the P1 stub of `comment.create` with the real handler and filled three route stubs: `GET /comments`, `POST /comments` and `POST /field-reports/:id/link-asset`. The cross-organisation test still expects `comment.create` to answer `UNKNOWN_MUTATION`, and its route-coverage check now lists the three routes as missing from the REST table. The comment handler correctly answers `NOT_FOUND` when an organisation B device targets an organisation A work order, and the three routes answer `NOT_FOUND` for organisation A ids.

Failing today:

```
× sync push: org B device targeting org A > comment.create
× route coverage > every route file and method is in the table, in the allowlist or a notImplemented stub
  + "GET comments", "POST comments", "POST field-reports/[id]/link-asset"
```
