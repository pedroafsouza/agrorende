# T05-007 · Realtime contract additions: location batch nack and tenant room

Status: OPEN
Requested by: T05 · Wave: W2
Target: `packages/contracts/src/realtime.ts` (owner: T01)
Kind: contract

## Problem
The `location:batch` acknowledgement in contracts only describes success. The gateway also needs to tell the device that a batch was rejected, so the device can keep the fixes. There is also no helper for the tenant room that `org:status` is sent to.

## Proposed change
```ts
export const LocationBatchNackSchema = z.object({ ok: z.literal(false), code: ErrorCodeEnum });
export type LocationBatchNack = z.infer<typeof LocationBatchNackSchema>;
export const orgRoom = (orgId: string) => `org:${orgId}` as const;
```

## Workaround in place
`apps/realtime/src/server.ts` defines `LocationBatchNack` and `orgRoom` locally.

## Impact if rejected
Mobile (T03) has to read the nack shape from the gateway source instead of from contracts.
