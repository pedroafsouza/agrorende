# T16-004 · Row selection slot in the shared DataTable

Status: OPEN
Requested by: T16 · Wave: W6
Target: `apps/web/src/components/data/DataTable.tsx` (owner: T04)
Kind: other

## Problem
The QR label sheet bulk action (OPS-07) needs rows that can be selected in the asset list. The shared `DataTable` has no selection support, and its row click navigates to the detail page. T16 built the selection inside `features/assets/AssetsListPage.tsx`: a checkbox column whose cell stops click propagation, a select-page checkbox in the header, and a bulk action region. It works and is tested, but every later bulk action would have to copy it.

## Proposed change
Add optional `selection?: { selectedIds: ReadonlySet<string>; onChange(ids: ReadonlySet<string>): void; label(row): string }` props to `DataTable`. When present, render a leading 48 dp checkbox column and a select-page header checkbox, both kept out of the row-click target. T16 would then move to the shared slot.

## Impact if not applied
None today. Future bulk actions will duplicate the page-local selection code.
