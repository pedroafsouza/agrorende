# T11-002: actionlint warning in the `checks` job of `ci.yml`

- **Status:** OPEN
- **Raised by:** T11 (web E2E and accessibility, wave W5)
- **Owner of the affected path:** T01 (`.github/workflows/ci.yml`, all jobs except `e2e`)

## Problem

The T11 final check runs `docker run --rm -v "$PWD:/repo" -w /repo rhysd/actionlint:latest .github/workflows/ci.yml`.
It exits with status 1 because shellcheck flags the "Start local services" step of the `checks` job,
which T11 does not own:

```
.github/workflows/ci.yml:52:9: shellcheck reported issue in this script: SC2034:warning:3:1: attempt appears unused. Verify use (or export if used externally) [shellcheck]
```

The `e2e` job written by T11 produces no findings.

## Requested change

In the `checks` job, rename the unused loop variable so shellcheck accepts the retry loop:

```yaml
for _ in $(seq 1 30); do curl -fsS http://localhost:4003/google/.well-known/openid-configuration > /dev/null && break; sleep 2; done
```

## Workaround

None is needed inside T11's lane. After this change, actionlint passes for the whole file.
