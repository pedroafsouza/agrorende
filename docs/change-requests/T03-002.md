# T03-002 · Mobile dependencies for gallery import, orientation, msw and UI tests

Status: OPEN
Requested by: T03 · Wave: W2
Target: `apps/mobile/package.json`, `pnpm-lock.yaml` (owner: T01)
Kind: dependency

## Problem
Several T03 scope items and acceptance criteria need packages that `apps/mobile` does not depend on. R4 freezes dependencies after T01.

- `expo-image-picker` and `expo-document-picker`: gallery import for `MediaCapture` and "Importar da galeria" when the camera is denied (ARCHITECTURE §21 permission matrix).
- `expo-screen-orientation`: the landscape lock for `SignaturePad`.
- `msw`: the AC asks for push and pull tests "with msw".
- `@react-native/assets-registry`: needed by the `jest-expo` preset. Without it the `ui` Jest project cannot start:

  ```
  Cannot find module '@react-native/assets-registry/registry' from '../../node_modules/jest-expo/src/preset/setup.js'
  ```

- `@testing-library/react-native` (with `react-test-renderer` matching React): needed for the UI-test AC (Wizard autosave and resume, ChecklistRunner completion, offline banner, SyncBadge states, recovery components, denied permissions, Ask office, language switch).

## Proposed change
Add these to `apps/mobile` with `npx expo install` so the versions match the SDK: `expo-image-picker`, `expo-document-picker` and `expo-screen-orientation` as dependencies; `msw`, `@react-native/assets-registry`, `@testing-library/react-native` and `react-test-renderer` as devDependencies. Refresh the lockfile.

## Workaround in place
- Capture is camera-only. When the camera is denied, `CameraSheet` shows `PermissionPrompt` with "ask again" and "open settings"; the gallery alternative from the matrix is not wired because there is no picker module. The user can close the sheet, and the step keeps its own required-photo validation.
- `SignaturePad` does not lock orientation. Its full-screen canvas modal declares `supportedOrientations={["landscape", "portrait"]}` and lays out for landscape when the device is rotated.
- The server is faked by `apps/mobile/test/helpers/fakeServer.ts`, a typed in-process implementation of the `@agrorende/contracts` sync, media and auth shapes, injected through the transport seam.
- The pure logic behind the UI components is unit-tested in the Node `engine` project (`test/engine/kit.test.ts`, `features.test.ts`): checklist completion, SyncBadge state collapse, recovery resolution, permission matrix copy, drafts save and resume, and ICU rendering in pt-BR and en. `test/ui/setup.ts` is ready for render tests once the dependencies land.

## Impact if rejected
No gallery import, no orientation lock, and the UI-test AC cannot be met with real render tests.
