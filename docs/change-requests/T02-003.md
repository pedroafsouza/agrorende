## Problem

## Change made
The six seam bodies in `packages/core/src/seams.ts` now delegate to `modules/users/service.ts`, `modules/media/service.ts`, `notify/index.ts` and `sync/touch.ts`; signatures are unchanged. The diff touches only those functions and five imports. Please confirm and mark APPLIED, or move the bodies if seam wiring is meant to happen elsewhere.

## Impact if rejected
W3 features (T06–T08) would hit `notImplemented` on every notification, media and technician lookup.

## Resolution
Confirmed and applied at the W2 gate. `packages/core/src/seams.ts` delegates every T02 seam to the module implementations, and the T04 and T05 seams have been delegated in the same pass (change requests T04-003 and T05-002). The core test suite passes with the delegation in place.
