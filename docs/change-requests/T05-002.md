# T05-002 · Delegate `locationSeams` to the locations module

Status: OPEN
Requested by: T05 · Wave: W2
Target: `packages/core/src/seams.ts` (owner: T01)
Kind: seam signature

## Problem
`locationSeams.lastFixes` and `locationSeams.liveSnapshot` in `packages/core/src/seams.ts` still throw `notImplemented`. T07 (work-order detail) and T09 (ops map) call these seams.

## Proposed change
```ts
import { locationSeamsImpl } from "./modules/locations/service.js";
export const locationSeams: LocationSeams = locationSeamsImpl;
```
`locationSeamsImpl` already satisfies `LocationSeams`, and its tests pass.

## Workaround in place
Callers inside T05 use `lastFixes` and `liveSnapshot` from `packages/core/src/modules/locations/service.ts` directly.

## Impact if rejected
Every consumer of `locationSeams` gets `INTERNAL NOT_IMPLEMENTED` at runtime.
