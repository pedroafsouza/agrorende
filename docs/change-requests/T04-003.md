# T04-003 · Delegate the T04 seams in `core/src/seams.ts` to the modules

Status: APPLIED
Requested by: T04 · Wave: W2
Target: `packages/core/src/seams.ts` (owner: T01)
Kind: seam signature

## Problem
`seams.ts` still returns `notImplemented` for the following seams, which W3 consumes: `seams.assets.getSummary`, `listSummaries`, `recomputeCondition`, `applyReadings` and `setCustody`; `seams.seasons.currentSeasonId` and `criticalWindowFor`; `seams.checklists.snapshotPublished` and `defaultTemplateId`; `seams.sites.getSummary`; and `seams.customers.getForEligibility`.

## Proposed change
Replace each stub with a call to the matching export in `packages/core/src/modules/{assets,seasons,checklists,sites,customers}/service.ts`. The signatures already match `@agrorende/contracts/seams`, so this is a one-line delegation per seam.

## Workaround in place
The module services implement each seam and are covered by the module tests. W3 can import them through the T04-001 export.

## Impact if rejected
W3 callers that go through `seams.ts` receive `NOT_IMPLEMENTED`.

## Resolution
Applied at the W2 gate. Every T04 seam in `packages/core/src/seams.ts` now delegates to the assets, sites, seasons, customers and checklists module implementations instead of throwing `notImplemented`.
