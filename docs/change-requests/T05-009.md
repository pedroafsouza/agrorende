# T05-009 · Raise the open-file limit of the development MongoDB

Status: OPEN
Requested by: T05 · Wave: W2
Target: `docker-compose.yml` (owner: T01)
Kind: other

## Problem
With several agents running test suites in parallel, the shared `mongo:8` container repeatedly crashed with "Too many open files". The default `nofile` limit is 1024, and every test database creates dozens of collections and indexes.

## Proposed change
```yaml
  mongo:
    ulimits:
      nofile: { soft: 65536, hard: 65536 }
```

## Workaround in place
T05 ran its suites against a private container started with `--ulimit nofile=65536:65536` on port 27018, by setting `MONGODB_URI`. The container was removed at the end of the task.

## Impact if rejected
Parallel test runs keep failing at random with `MongoNetworkError` or `ECONNREFUSED`.
