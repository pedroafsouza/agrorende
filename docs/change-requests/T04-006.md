# T04-006 · Add a test runner to `apps/web`

Status: OPEN
Requested by: T04 · Wave: W2
Target: `apps/web/package.json`, `apps/web/vitest.config.ts` (owner: T01)
Kind: dependency

## Problem
`apps/web` has no `test` script and no Vitest or Testing Library dependencies. Because of that, the route tests and component tests in T04.18 cannot be written or run. R4 forbids `pnpm add`.

## Proposed change
Add `vitest`, `@testing-library/react`, `@testing-library/user-event` and `jsdom` as dev dependencies. Add `"test": "vitest run"` and a `vitest.config.ts` with the `@/` alias and a `jsdom` environment for `*.test.tsx`.

## Workaround in place
The pure helpers are exported so that they can be tested later: `safeNext`, `officeContactMissing`, `deviceWarnings`, `whatsappShareUrl`, `notificationHref` and the formatters in `lib/format.ts`. The core logic is covered by the `packages/core` module tests.

## Impact if rejected
The web pages and routes stay untested until T10.
