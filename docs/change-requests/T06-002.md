# T06-002 · Point the home widget registry at the report widgets

Status: OPEN
Requested by: T06 · Wave: W3
Target: `apps/mobile/src/features/home/widgets.ts` (owner: T03)
Kind: other

## Problem
The home registry re-exports `QuickReportCard` and `MyReportsCard` from the T03 placeholder `./cards`. T06 owns the real widgets but cannot edit the registry, so the home screen still shows the plain link cards without the resume-draft action (EC-FR-12) or the open-report count.

## Proposed change
```ts
export { DutyCard, NextJobCard, RentalsTodayCard, SyncCard } from "./cards";
export { MyReportsCard, QuickReportCard } from "../reports/widgets";
```
The new widgets keep the test ids `home-quick-report` and `home-my-reports`.

## Workaround in place
`apps/mobile/src/features/reports/widgets.tsx` exports both widgets, and `features/reports/index.ts` re-exports them.

## Impact if rejected
Home keeps the placeholder cards. Reports still work from the Reports tab, and drafts can still be resumed from the wizard.
