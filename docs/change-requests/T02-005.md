# T02-005 · Move notification templates into `@agrorende/i18n`

Status: OPEN
Requested by: T02 · Wave: W2
Target: `packages/i18n/src/messages/{pt-BR,en}/notifications.json` (owner: T01)
Kind: i18n

## Problem
Server-rendered notification title and body templates (ARCHITECTURE §6.5) belong in the `notifications` namespace of `@agrorende/i18n`, which T02 does not own.

## Proposed change
Copy `NOTIFICATION_TEMPLATES` from `packages/core/src/notify/templates.ts` into the `notifications` namespace for pt-BR and en (keys `<TYPE>.title` and `<TYPE>.body`), then make `renderNotification` read from `@agrorende/i18n`.

## Workaround in place
`packages/core/src/notify/templates.ts` holds both locales for every `NotificationType`, with a small ICU renderer (`{name}` and `plural`) and a test that every type has both locales.

## Impact if rejected
Translators must edit a TypeScript file, and `pnpm i18n:check` does not cover notification text.
