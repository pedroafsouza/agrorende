# T20-005 · Mount the mobile organisation-paused banner

Status: OPEN
Requested by: T20 · Wave: W3
Target: `apps/mobile/app/**` home or tab layout and the session store (owner: T03)
Kind: mount point

## Problem
EC-PLT-40 requires field users to see "Company access paused" while the organisation is SUSPENDED or CANCELLED, so they keep recording offline and know the outbox will flush later. T20 filled `apps/mobile/src/features/tenancy/OrgStatusBanner.tsx`, which renders only for those two statuses, with the copy in `src/i18n/*/tenancy.json`.

## Proposed change
Render `<OrgStatusBanner status={org.status} />` from `src/features/tenancy` under the header of the field home screen, reading the organisation status from the session and `/auth/me`. Refresh it when the realtime `org:status` event or a `sync:poke` arrives.

## Workaround in place
None; the component is tested in `apps/mobile/test/ui/tenancy.test.tsx` but not mounted.

## Impact if rejected
Field users see push failures without explanation while the company is paused.
