# T11-001 · Playwright test runner and axe dependencies for the web E2E suite

Status: APPLIED
Requested by: T11 · Wave: W5
Target: `apps/web/package.json`, `pnpm-lock.yaml` (owner: T01)
Kind: dependency

## Problem
ARCHITECTURE §2 and §15 name Playwright (`@playwright/test`) as the web E2E runner and `@axe-core/playwright` for accessibility checks, and the T11 card runs `pnpm --filter web exec playwright test`. Neither package is a dependency of `apps/web`, and neither is in `pnpm-lock.yaml`. Only the root `@playwright/cli` (review screenshots) is installed. As a result:

- `pnpm --filter web exec playwright test` fails with "Command "playwright" not found".
- `pnpm --filter web typecheck` cannot resolve `@playwright/test` and `@axe-core/playwright` in `apps/web/playwright.config.ts` and `apps/web/e2e/**`, because the web `tsconfig.json` includes every `**/*.ts` file.

Rule R4 forbids T11 from running `pnpm add`.

## Proposed change
Add two devDependencies to `apps/web/package.json` and refresh the lockfile:

```diff
   "devDependencies": {
     "@agrorende/config": "workspace:*",
+    "@axe-core/playwright": "^4.13.0",
+    "@playwright/test": "^1.64.0",
     "@tailwindcss/postcss": "^4.1.18",
```

Command: `pnpm --filter web add -D @playwright/test@^1.64.0 @axe-core/playwright@^4.13.0`.

`@playwright/test@1.64.0` matches the `playwright@1.64` line already pulled in by the root `@playwright/cli`, so CI's `pnpm exec playwright install --with-deps chromium` in `copilot-setup-steps.yml` keeps working.

## Workaround in place
For local verification only, T11 installed `@playwright/test@1.64.0` and `@axe-core/playwright@4.13.0` with `npm install` into the git-ignored scratch folder `.data/e2e-deps/`, and symlinked them into `apps/web/node_modules/@playwright/test`, `apps/web/node_modules/@axe-core/playwright` and `apps/web/node_modules/.bin/playwright`. Nothing tracked was changed. The next `pnpm install` replaces the symlinks with the real packages once this request is applied.

## Impact if rejected
The web E2E suite, its CI job and the web typecheck cannot run on a clean checkout: `pnpm --filter web typecheck` fails on the e2e files.

## Resolution

Applied at the W5 gate. `@playwright/test` (^1.64.0) and `@axe-core/playwright` (^4.13.0) are now real `devDependencies` of `apps/web`, installed from public npm and recorded in `pnpm-lock.yaml`, so `pnpm install --frozen-lockfile` provides them in CI and locally. The `apps/web/node_modules` symlinks into `.data/e2e-deps` are gone (the hoisted install provides the real packages) and the scratch folder `.data/e2e-deps` is deleted. The `e2e` job in `.github/workflows/ci.yml` installs the browser with `pnpm --filter web exec playwright install --with-deps chromium`.

`pnpm-workspace.yaml` also gained an `overrides` block. It pins the `playwright`, `playwright-core` and `@playwright/test` dependencies of the root `@playwright/cli` toolkit package to 1.64.0. Without it, the alpha build that `@playwright/cli` requests was hoisted and shadowed the `playwright` binary, and `pnpm --filter web exec playwright test` failed with "two different versions of @playwright/test". The full suite was run once at the gate.
