## Problem


## Proposed change
Apply the patch below. It was applied to a copy of the file and run with `MONGODB_DB=agrorende_t16 npx vitest run`: all eight new rows pass, and none of the five keys remains in the coverage failure. The remaining failures in that run (`comment.create`, `fuelLog.create` and the other routes in the coverage list) belong to T14, T15 and T17.
