# T15-003 · Update the web mount-point test now that `BillingActions` is implemented

Status: RESOLVED BY OWNER
Requested by: T15 · Wave: W6
Target: `apps/web/src/features/comments/mountPoints.test.tsx` (owner: T17)
Kind: test

## Problem
T10 left `BillingActions` as an empty mount point and asserted that it "renders nothing". T15 implemented it in `apps/web/src/features/billing/BillingActions.tsx`: it now renders the billing panel (create, open and PDF actions) for a work order or a rental. The case `it("BillingActions renders nothing", …)` therefore fails. The neighbouring `ExternalCostPanel renders nothing` case fails for the same reason after T14's work and is not part of this request.

## Proposed change
Delete the `BillingActions renders nothing` case and the now unused `BillingActions` import from `apps/web/src/features/comments/mountPoints.test.tsx`. The behaviour is covered by `apps/web/src/features/billing/BillingActions.test.tsx`.

## Workaround in place
None needed at runtime. `BillingActions.test.tsx` covers the component.

## Impact if rejected
`pnpm check:only web` stays red on one test case that asserts the old stub behaviour.

## Resolution
Before the end of T15, the owner (T17) had already rewritten the case to assert only that `BillingActions` and `ExternalCostPanel` are exported functions. `apps/web` tests pass (41 files, 237 tests). No further action is needed; this request is kept for the record.
