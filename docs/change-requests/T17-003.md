# T17-003 · Show the unread notification count on the More screen

Status: APPLIED
Requested by: T17 · Wave: W6
Target: `apps/mobile/src/features/settings/MoreScreen.tsx` (owner: T03)
Kind: other

## Problem
T17 built the mobile notification centre (PLT-08) at `app/(app)/notifications.tsx`, reached from the existing *Notifications* entry on the More screen. The entry shows no unread count, so a field user has no hint that new comments or job changes are waiting there. T17 provides the hook `useUnreadNotifications()` in `src/features/notifications/useUnreadNotifications.ts`, which re-reads the local count after every sync and local write.

## Proposed change

```diff
--- a/apps/mobile/src/features/settings/MoreScreen.tsx
+++ b/apps/mobile/src/features/settings/MoreScreen.tsx
@@
+import { useUnreadNotifications } from "../notifications/useUnreadNotifications";
@@
   const snapshot = useSyncSnapshot();
   const pending = snapshot.pendingMutations + snapshot.pendingUploads;
+  const unread = useUnreadNotifications();
@@
-            right={entry.id === "sync" && pending > 0 ? <Badge labelKey="sync.pending.summary" values={{ count: pending }} tone="warning" /> : undefined}
+            right={
+              entry.id === "sync" && pending > 0 ? (
+                <Badge labelKey="sync.pending.summary" values={{ count: pending }} tone="warning" />
+              ) : entry.id === "notifications" && unread > 0 ? (
+                <Badge labelKey="common.notificationCentre.unread" values={{ count: unread }} tone="info" />
+              ) : undefined
+            }
```

The key `common.notificationCentre.unread` already exists in `src/i18n/{pt-BR,en}/common.json` (en: "{count, plural, =0 {No unread notifications} one {# unread} other {# unread}}"), so no new translation is needed.

## Workaround in place
The notification centre itself shows an unread header and a *Mark all as read* action, and push notifications still arrive. Only the hint on the More screen is missing.

## Impact if rejected
Users have to open the notification centre to discover unread items.

## Resolution

Applied by the W6 gate. The notifications entry on the More screen shows an info badge with the unread count from `useUnreadNotifications()`. Covered by `apps/mobile/test/ui/moreScreen.test.tsx`.
