# T07-002 · `confirmMeterJump` on `workOrder.complete`

Status: APPLIED
Requested by: T07 · Wave: W3
Target: `packages/contracts/src/mutations/workOrders.ts` (owner: T01, frozen foundation)
Kind: contract addition

## Problem
EC-WO-14 asks for a "confirm big jump" flow when an hour-meter reading is much higher than expected. `WorkOrderCompletePayloadSchema` has `hourMeterReading`, `meterReplaced` and `meterPhotoMediaId`, but no flag that says the technician confirmed an unusually large jump. Without that flag the server can only reject a large jump or accept it silently.

## Proposed change
Add `confirmMeterJump: z.boolean().optional()` to `WorkOrderCompletePayloadSchema`. When it is true, the server accepts the reading, records `meterJumpConfirmed: true` in the completion activity and raises the existing office attention item.

## Workaround in place
`packages/core/src/modules/workOrders/field.ts` rejects a jump larger than `max(1, elapsed hours) × 24` hours since the last reading with `METER_READING_JUMP`. The mobile complete screen shows the recovery: the technician corrects the reading, or uses the existing meter-replaced path with a photo, which bypasses the check. A real but unusual jump therefore needs the meter photo.

## Impact if rejected
Technicians with a genuine large jump must attach a meter photo through the meter-replaced path, which records the reading as a meter replacement.

## Resolution

The orchestrator applied the server side of this request at the W3 gate. `WorkOrderCompletePayloadSchema` in `packages/contracts/src/mutations/workOrders.ts` gained an optional `confirmMeterJump` boolean. When it is true, `packages/core/src/modules/workOrders/field.ts` skips the `METER_READING_JUMP` guard and records `meterJumpConfirmed: true` and `attention: true` in the meta of the `workOrder.complete` activity, so the office sees the confirmed jump. The mobile completion screen does not yet offer a "confirm reading" action that sends the flag; that small UI step is listed as a gap for T10 in `docs/progress/W3-gate.md`.
