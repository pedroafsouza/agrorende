# T02-004 · Implement or retire `events.emit` / `events.dispatchPending`

Status: APPLIED
Requested by: T02 · Wave: W2
Target: `packages/core/src/events/index.ts` (owner: T01)
Kind: seam

## Problem
`packages/core/src/events/index.ts` still throws `notImplemented` for `emit` and `dispatchPending`. T02 writes realtime and push events straight into `event_outbox` through `notify/index.ts` `writeOutbox(tx, type, {rooms, data, pushNotificationIds?})`, and the worker job `apps/worker/src/jobs/events.dispatch.ts` dispatches rows older than 10 seconds. The skeleton's `DomainEvent` shape is not used by anyone.

## Proposed change
Either implement `emit(tx, event)` as a thin call to `writeOutbox` (rooms derived from `entity` and `organizationId`) and `dispatchPending()` as a post-commit publish of the request's rows, or delete the file so nobody calls a dead stub.

## Workaround in place
All T02 producers call `writeOutbox`; post-commit fan-out happens in the worker every 5 seconds with a 10-second grace (ARCHITECTURE §7.3).

## Impact if rejected
A W3 task that calls `events.emit` fails with `NOT_IMPLEMENTED` at runtime.

## Resolution
Applied at the W2 gate. `packages/core/src/events/index.ts` is now implemented. `emit(tx, event)` inserts a row into `event_outbox` inside the caller's transaction, records its id for the current process and returns it. When `rooms` is omitted and an `entity` is given, the event goes to the organisation's ops room. `dispatchPending(ids?)` is the post-commit fast path. It reads the undispatched rows, publishes each one on the realtime Redis channel, enqueues `notifications.push` (and `auth.appleRevoke` where relevant) with the event id as the BullMQ job id, then marks the row dispatched. It never throws; it returns the dispatched and failed counts, and the worker's `events.dispatch` job stays the retry path for anything it misses. `writeOutbox` in `packages/core/src/notify/index.ts` now delegates to `emit`, so there is a single writer of `event_outbox`. A new `events/index.test.ts` covers both functions.
