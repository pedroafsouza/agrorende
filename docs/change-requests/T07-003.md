# T07-003 · Mount `NextJobCard` on the mobile home

Status: OPEN
Requested by: T07 · Wave: W3
Target: `apps/mobile/src/features/home/widgets.ts` (owner: T03)
Kind: wiring

## Problem
DELIVERY-PLAN §3.3 says that T07 provides `NextJobCard` from `apps/mobile/src/features/jobs/widgets.tsx` and that T03 consumes it in `features/home/widgets.ts`. The home registry still points at the T01 placeholder.

## Proposed change
In `apps/mobile/src/features/home/widgets.ts`, take `NextJobCard` from the jobs feature instead of the placeholder in `./cards`, alongside the T06-002 change:

```ts
export { DutyCard, RentalsTodayCard, SyncCard } from "./cards";
export { NextJobCard } from "../jobs/widgets";
```

## Workaround in place
`NextJobCard` is implemented and tested in `apps/mobile/src/features/jobs/widgets.tsx`. It takes no props and reads the local store, so mounting it is a one-line change.

## Impact if rejected
The home screen keeps showing the placeholder, and technicians reach their next job through the Jobs tab only.
